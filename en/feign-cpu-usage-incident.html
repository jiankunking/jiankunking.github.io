Feign Calls Pegged the CPU: Repeated HttpMessageConverter Initialization

Posted on 2024-10-13 Edited on 2026-09-29 Views: Word count in article: 3k Reading time ≈ 3 mins.
A production postmortem: Feign calls pegged the CPU because HttpMessageConverters were re-initialized on every call, re-running class loading and Jackson setup. Full diagnosis chain and fixes.

A record of one application incident: analysis, investigation, resolution.

A CPU alert came in and the business team reported that API responses were taking too long. This post records the entire process — from the alert, through diagnosis, to root cause analysis — ending at a CPU saturation problem caused by Feign calls.

🕰️ Version note: this post was written in 2024, on a stack of Feign 10.1.0, Spring 5.1.6, Java 8 (1.8.0_242). The ecosystem moves fast; read it against the versions you actually use.

Background

On the morning of the 9th, a CPU alert came in; at the same time, the business team reported that upstream services depending on this one were seeing very slow API responses.

Traffic

Peak QPS per instance was around 100.

Why care about QPS? Because 100 QPS shouldn’t consume this much CPU — and the request and response bodies were small.


POD monitoring

POD quotas:

  • CPU request 2 cores, CPU limit 3 cores

  • CPU load stayed high;

ARMS

Looking at the trace monitoring, we saw that the time was going into the customer service calling external APIs via Feign.

Interim mitigation

Scale out instances and increase the CPU allocation.

Root cause analysis

The investigation of the third-party APIs and the open-platform gateway is omitted here; the conclusion was that neither the third-party APIs nor the open-platform gateway had a problem.

Summary

When you customize Feign’s codecs with SpringEncoder / SpringDecoder, avoid re-initializing HttpMessageConverters on every call. If you don’t need the default HttpMessageConverters, pass false as the first argument when constructing HttpMessageConverters, so the defaults are never initialized.
