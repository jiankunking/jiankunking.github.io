4 篇代表文章

第一次来，不必从归档第一篇读起。这里按你正在解决的问题组织文章：先看一个具体案例，再沿专题了解原理、取舍和可复用的方法。

正在排查线上故障？

  • 网关报 504，总是卡在 15 秒 → APISIX 连接超时排查：用代码、请求数据和抓包对齐证据。
  • 升级后流式请求失败，CPU 还打满了 → API7 升级故障复盘：拆开两个独立缺陷，分别复现和验证。
  • Go 客户端出现大量 TIME_WAIT → HTTP Client 连接复用与调优：从请求代码与连接生命周期入手。
  • Elasticsearch 报 Parent Data Too Large → 7.6.2 熔断排查案例：机制分析仍适用，JVM 参数按你的版本核对。

正在做选型或架构设计？

  • 怎么评估一个 AI 网关 → AI 网关选型评分卡：按能力、性能和生产成熟度逐项验证，不做产品排名。
  • 模型管理和网关应该怎么分工 → 从模型管理到 AI 网关：把资产、权限、配额和用量回流连起来。
  • 不能停机，如何迁移 Elasticsearch → 数据同步、比对与切换方案：先看案例规模和约束，再判断能否借鉴。
  • 多个云、多个集群的入口怎么组织 → 多云高可用网关架构：围绕部署、安全边界和故障隔离做取舍。
